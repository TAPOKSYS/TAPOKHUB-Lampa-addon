English

One plugin file for everyone. It needs your own TapokHub server: you enter its address in the plugin settings.

  1. Set up a server (one command, it runs in Docker): quick start. Its address looks like https://tapok.example.com.
  2. In Lampa: Settings → Extensions → Add plugin, paste the address above, restart Lampa.
  3. Settings → TapokHub → “Enter the server address by hand” (or paste it from the clipboard).
  4. Settings → TapokHub → Authorization → “Sign in with a CUB account”.

Lampa opened over https:// needs an https:// server address; the Lampa app on a TV or phone also works with http:// in a home network.

Русский

Один файл плагина для всех. Нужен свой сервер TapokHub: его адрес вводится в настройках плагина.

  1. Поставьте сервер (одна команда, работает в Docker): быстрый старт. Адрес вида https://tapok.example.com.
  2. В Lampa: Настройки → Расширения → Добавить плагин, вставьте адрес выше, перезапустите Lampa.
  3. Настройки → TapokHub → «Ввести адрес сервера вручную» (или «Вставить адрес сервера из буфера обмена»).
  4. Настройки → TapokHub → Авторизация → «Войти через аккаунт CUB».

Lampa, открытой по https://, нужен адрес сервера с https://; приложение Lampa на телевизоре и телефоне работает и с http:// в домашней сети.
